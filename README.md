# Viralup first draft

A responsive React/Vite clone of the user-approved [Viralup Framer reference](https://viralup.framer.website/), including the full marketing homepage and a reference-matched `/contact-us` route with locally packaged campaign media.

## Run locally

```bash
npm install
npm run dev
```

Create the production build with `npm run build`; the generated site is written to `dist/`.

## Included

- Full hero, process, projects, about, services, pricing, team, testimonial, FAQ, contact, and footer sequence.
- Dedicated `/contact-us` page with responsive contact form, help card, FAQ, rotating campaign carousel, and footer.
- Desktop and mobile responsive layouts.
- Working menu, pricing switch, FAQ disclosure, and newsletter validation.
- Local fonts, images, video posters, and source videos from the pinned public reference.
- `PRODUCT.md`, `DESIGN.md`, `brand-spec.md`, and `.impeccable/design.json` project documentation.

This is a first-draft implementation for review. Reference media provenance is documented in `brand-spec.md` and embedded in, or stored beside, each shipping raster.
