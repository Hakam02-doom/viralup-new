# Viralup Brand Spec

## Reference

- Approved visual authority: https://viralup.framer.website/
- Full-page reference capture: `work/viralup-reference-full.png`

## Identity assets

- Logo: `public/assets/viralup/logo.svg` — reconstructed as a standalone file from the reference site's inline SVG mark and word treatment.
- Partner marks: `public/assets/viralup/partner-1.svg` through `partner-5.svg` — sourced from the reference page.

## Typography

- Inter Display: `public/assets/viralup/inter-display.woff2` — sourced from the reference page's Framer asset.
- Instrument Serif: `public/assets/viralup/instrument-serif.woff2` — sourced from the font file used by the reference page.

## Media

- Hero and project MP4 files: `public/assets/viralup/*.mp4` — sourced from the reference page's observed media assets.
- Video poster frames: `public/assets/viralup/posters/` — extracted at one second from the corresponding sourced reference videos to prevent unloaded or off-screen media from appearing black.
- Process, mission, services, team, pricing, and testimonial imagery: `public/assets/viralup/` — sourced from the reference page and renamed by usage.
- Pricing arrow: the reference's original Framer raster is preserved as `pricing-arrow.png`; its alpha and folded shading are retained in `pricing-arrow-blue.png`, a blue-channel treatment that reproduces the reference's cobalt card appearance with the overlaid white streak.

## Color tokens

- Canvas: `#f5f5f5`
- Surface: `#ffffff`
- Ink: `#000000`
- Secondary ink: `#5b5b5b`
- Accent: `#047efb`
- Warm rating accent: `#ff8f00`

## Shape and motion

- Controls and compact cards: 8px radius.
- Major media and grouped surfaces: 16–20px radius.
- Motion is restrained: one hero entrance, looping source videos, small hover lift, and accordion disclosure.

## Provenance note

All shipping photography, posters, partner marks, fonts, and videos in this draft are sourced from the user-approved public reference website. No identity-critical image is AI-generated or substituted with CSS artwork.
